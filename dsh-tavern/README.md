# 酒馆工作区（dsh-tavern）

给 dsh 用的酒馆创作工作区。

- **入口**：`AGENTS.md`——角色定位、目录、解析工具、工作流程、护栏与红线。
- **方法论**：`SKILL.md`（完整版，第一次相关任务必读）；`SKILL-QUICK.md`（速查与诊断，不能替代完整版）。
- **落地脚本**：`persona_new.py`（部署于 `/opt/tavern-bot/`，draft → SillyTavern persona，dry-run 默认，`-design.md` 拒写）。
- **产出**：`drafts/`（`personas/` `plotnotes/` `tags/`，不入库）。

版本随 `tt-backup` 仓库管理；本地改动请同步进仓库，避免多窗口版本漂移。
